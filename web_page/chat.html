Acciones

El botón "Activar Voz" en la cabecera envía una solicitud al servidor local para iniciar el pipeline (grabación → transcripción → respuesta → TTS). El servidor integrado se encuentra en ai_core.py y expone el endpoint POST /api/run_main que ejecuta el pipeline o lo encola.

Estado: Inactivo

Consejos rápidos

- Usa mensajes cortos para respuestas orales más directas.
- Di "salir" para detener sesiones de voz si se integra con main.py.
- Mantén el micrófono libre cuando la grabadora esté activa.

Privacidad

Las grabaciones temporales y archivos TTS se gestionan localmente por main.py y se limpian al finalizar la sesión.
